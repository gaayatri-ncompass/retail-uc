Project Title : Retail Sales Analytics Data Warehouse Modelling

The main aim is to create a dimensional data warehouse to enable analysis of sales, customers and product performance for a fictional retail chain called 'ShopperStop'.

Source Data:
- We are provided with 6 CSV Files. Each containing information about:
  1. Customers
  2. Inventory
  3. Products
  4. Sales
  5. Stores
  6. Suppliers

Project Flow: 
1. Initially, I went through the data and identified relationships between the key entities and drew an E-R model.
2. Then I designed a Star Schema dimensional model with one fact table and 5 dimensional tables.
3. Planned out the project structure, and identified helper functions I would need for ETL.
4. Wrote a function to generate the dates dimension.
5. I wanted to Extract -> Load to Staging Area -> Perform Transformations -> Load to Data Warehouse.
